# 🔬 Semiconductor Yield Loss Analysis & Gemini XAI Diagnostics

An end-to-end Machine Learning pipeline and Explainable AI (XAI) diagnostic tool for wafer fab process engineers, leveraging **XGBoost Classifier** and **Gemini 3.6 Flash** LLM.

---

## 📌 Project Overview
In advanced semiconductor manufacturing, inline sensor datasets exhibit high dimensionality and extreme class imbalance (~93% Pass vs ~7% Fail). This project demonstrates:
1. **Data Preprocessing & Cleaning**: Removal of zero-variance features and median imputation for sparse sensor data.
2. **Imbalanced Machine Learning**: XGBoost classification tuned with `scale_pos_weight` to capture yield failure signatures.
3. **Feature Attribution (Yield Killers)**: Extraction of top sensor parameters driving yield loss.
4. **Gemini LLM XAI Diagnostics**: Automatic generation of plain-English equipment and process tuning recommendations for fab engineers.
